# ⚡ AI News Radar

An automated, live, dark-themed AI intelligence feed that curates breaking artificial intelligence headlines, research breakthroughs, robotics updates, and policy announcements.

## ✨ Features

- **Dark-Themed UI:** Sleek glassmorphic card design, pulse status indicator, and responsive typography.
- **Clickable Cards:** Click anywhere on a news card to open the direct article or primary source in a new tab.
- **Rich Metadata:** Displays the headline, source publication, exact timestamp, and executive summary for each story.
- **Web-Ready:** Clean single-page application (`index.html`) optimized for local viewing and immediate hosting on GitHub Pages.

## 🚀 Getting Started

### Local Viewing
Simply open `index.html` in any web browser:
```bash
# Windows
start index.html
```

### Live Deployment
Your live feed is hosted and running directly on GitHub Pages:
🔗 **[https://shimaa-os.github.io/ai-news-radar/](https://shimaa-os.github.io/ai-news-radar/)**

## 🛠️ Tech Stack
- Pure semantic HTML5 / CSS3 (CSS Variables, Flexbox, Glassmorphism, CSS Animations)
- Native anchor card linking (no fragile script navigation)
- Google Fonts (`Inter`)
