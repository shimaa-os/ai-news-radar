# ⚡ AI News Radar

An automated, live, dark-themed AI intelligence feed that curates breaking artificial intelligence headlines, research breakthroughs, robotics updates, and policy announcements.

## ✨ Features

- **Dark-Themed UI:** Sleek glassmorphic card design, pulse status indicator, and responsive typography.
- **Clickable Cards:** Click anywhere on a news card to open the direct article or primary source in a new tab.
- **Rich Metadata:** Displays the headline, source publication, exact timestamp, and executive summary for each story.
- **Web-Ready:** Includes both `ai_newa.html` and `index.html` for local viewing or immediate hosting on GitHub Pages.

## 🚀 Getting Started

### Local Viewing
Simply open `ai_newa.html` or `index.html` in any web browser:
```bash
# Windows
start index.html
```

### GitHub Pages Deployment
1. Go to repository **Settings** > **Pages**.
2. Under **Build and deployment** > **Source**, choose **Deploy from a branch**.
3. Select `main` branch and `/ (root)` folder, then click **Save**.
4. Your live feed will be accessible at: `https://shimaa-os.github.io/ai-news-radar/`

## 🛠️ Tech Stack
- Pure HTML5 / CSS3 (CSS Variables, Flexbox, Glassmorphism, CSS Animations)
- Vanilla JavaScript for card navigation and interaction
- Google Fonts (`Inter`)
